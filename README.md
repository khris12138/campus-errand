# 顺路跑腿 · 校园互助平台

**在线体验（点开即用）：<https://khris12138.github.io/campus-errand/>**

无需安装、无需登录。手机上直接全屏；电脑上是一台手机模型，点屏幕即可操作。

---

## 30 秒体验路线

1. 点 **「我要发单」** —— 页面已填好示例内容，滑到底部点黄色 **「发布任务」**。
2. 约 2 秒后，出现骑手 **陈知远** 的接单页：姓名、照片、蓝色打勾，标注「在校学生身份核验」。
3. 点 **「查看核验」** —— 校园卡认证、身份证实名、edu 教育邮箱验证码，三重核验均已通过。
4. 返回首页点 **「我要接单」** —— 可按快递、带饭、代买、占座、打印筛选；点任意任务查看详情并接单。

> 页面中的姓名、学号、邮箱、订单、信用分均为演示数据，仅用于展示产品结构与交互。

## 本地打开

`index.html` 是单文件原型，无框架、无依赖、无构建步骤：

```bash
open index.html
```

也可以直接把 `index.html` 拖进浏览器。
